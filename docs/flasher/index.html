DOLOS

USB-HID Payload Runner

boots SAFE · never types until you arm it by hand

Flash it from your browser

Plug the ESP32-S3-GEEK into a USB port, confirm authorized use, click install, and pick the serial port. No toolchain, no drivers.

Your browser can't talk to USB serial. Open this page in Chrome or Edge on a desktop. This page must be served over HTTPS to flash. Use the hosted link.
Needs a Chromium browser (Chrome / Edge / Opera) on desktop — Web Serial isn't in Safari or Firefox.
⚖️ Authorized security testing only. Dolos emulates a USB keyboard. Using it to inject keystrokes into a computer you do not own or have written permission to test is illegal in most jurisdictions (e.g. computer-misuse / unauthorized-access laws). You are responsible for how you use it. Read the ethics & legal notes first.
Why it won't fire by accident. Dolos boots SAFE and sends nothing. Firing takes two deliberate holds of the BOOT button at the device (SAFE → ARMED → 3-2-1 countdown → run), and a tap aborts at any stage. Hold BOOT while plugging in for FLASH MODE, where USB-HID never starts at all. The payload is plain text you can read on the SD card.

What it does

DuckyScript-style payloads — STRING, DELAY, GUI/CTRL/ALT combos, F-keys, REPEAT
On-screen mission control — SAFE / ARMED / countdown / live line progress
Payloads from microSD — drop a PAYLOAD.TXT you can inspect
Two-stage arming + abort — nothing types until you decide

What you need

Board
Waveshare ESP32-S3-GEEK
Port
USB-A (the GEEK's own plug), data-capable
Browser
Chrome / Edge, desktop
Image
single file, flashed at 0x0

Steps

  1. Plug the GEEK into a USB-A port. USB-C-only laptop? Use an A-to-C adapter.
  2. Tick the authorization box, click Install Dolos, choose the serial port. (If none appears, hold BOOT while plugging in.)
  3. Let it erase and write — about a minute.
  4. It reboots into Dolos SAFE. It will not type until you arm it by hand.
